ルートマップ ZED運賃 条件

航空会社職員向けの割引搭乗制度 ZED運賃(Zonal Employee Discount)について、 flyzed.info に掲載されている全263社のページを個別に取得し、原文サイトの見出し構成 (Embargoes / Flight listing / Visas and Passports / Flights excluded・included / Baggage / Boarding policy / Check-in / Dress code / Special service requests など、社ごとに異なる)を 保持したまま日本語に訳したものです。固定項目に圧縮せず、各社ページに実際にある見出しをそのまま再現しています。

⚠
必ず一次情報で最終確認してください。 本ページは原文の翻訳であり、公式規定と食い違う場合は myIDTravel や所属航空会社の Staff Travel 部門の案内が優先されます。各カードの「原文の最新を確認」ボタンで、 翻訳時点から flyzed.info の原文が変わっていないかをその場で照合できます。
