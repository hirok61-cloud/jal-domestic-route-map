✈ HND-GMP収集
合言葉はこのブックマークレットの中に埋め込まれます（あなたの端末内だけ）。サーバや他人には渡りません。
② 使い方
iPhone / Safari
PC

入れ方（初回だけ・1〜2分）

  1. 上の コピー でブックマークレットをコピー
  2. Safariでこのページをブックマークに追加（共有 → ブックマークを追加）
  3. ブックマーク一覧 → いま追加したものを編集
  4. タイトルを「HND-GMP収集」に、下のURL欄を全部消してコピーした内容をペーストして保存

毎回の更新（約5分）

  1. Safariで myIDTravel を開いてログイン
  2. ブックマークから「HND-GMP収集」をタップ。基本はこれだけです。
    セッションが未準備のときは自動で HND → GMP を検索して準備し、そのまま収集に入ります（バーに「セッションを準備中（自動検索）…」と出ます）
  3. 画面上部の赤いバーで進捗（○/60）が進みます。緑になれば保存完了
  4. 収集が終わるまで画面をつけたまま置いてください。自動で画面が消えないようにしますが、電源ボタンで消したり他アプリに切り替えると止まります（Safariは前面のまま）
自動検索がうまくいかないときは「セッションが未準備」と赤く出て止まります。その場合は自分で myIDTravel で HND → GMP を1回検索（出発 HND・到着 GMP を入れて Find Flights）してから、もう一度タップしてください。
ログインが切れているときは「ログインしてください」と出ます。
  1. 上の「✈ HND-GMP収集」ボタンをブックマークバーにドラッグ（またはコピーして新規ブックマークのURLに貼付）
  2. myIDTravel を開いてログイン
  3. 「HND-GMP収集」をクリック。セッション未準備なら自動で HND → GMP を検索して準備し、そのまま収集 → 画面上部のバーで進捗、緑で完了
  4. うまく準備できないときは自分で HND → GMP を1回検索（Find Flights）してから、もう一度クリックしてください
PCで常時使うなら、拡張機能版（毎日自動収集）の方が便利です。詳しくはデスクトップの HND-GMP-monitor/README を参照。
③ 保存されると

保存に成功すると 空席モニター の「収集回数」が増え、最新データに切り替わります（数秒〜十数秒）。手動でもiPhoneでも同じ場所に貯まります。
