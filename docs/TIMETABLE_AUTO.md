# 国内線ダイヤの自動更新

ルートマップ（`/`）の便データは `data/domestic-timetable.js` にあり、
GitHub Actions（`.github/workflows/update-timetable.yml`）が**毎週月曜 03:30 JST**に作り直す。
手動で動かすときは GitHub の Actions タブ →「国内線ダイヤの自動更新」→ Run workflow。

```
駅探（空港別のJAL時刻表 87ページ） ─→ 便名・路線・時刻
JAL公式の空席データ（Supabase GET）─→ 羽田路線の実機材
FlightAware（週150便ずつ順番に）  ─→ それ以外の便の機材
        │
scripts/update_timetable.py
        ├─ data/domestic-timetable.js … ページが読むデータ（meta と routes）
        └─ data/domestic-aircraft.json … 便名ごとの機材・運航会社の控え
        │ 変更があるときだけ commit → push → Workers Builds が本番へ
```

## なぜ週1回か

ダイヤが大きく変わるのは年2回（3月最終日曜・10月最終日曜）で、期中の変更（季節便の開始、
増減便）も週単位で追えば十分。月曜に揃えているのは、駅探の時刻表が「その日に飛ぶ便」を
出すため。曜日を揃えないと、曜日運航の便が出入りして偽の差分になる
（手動実行を月曜以外にすると、曜日運航の差分が出ることがある）。

## 表示される日付の意味

- **`meta.asOf`**（ページの「◯年◯月◯日時点」）… **便名・路線・時刻が最後に変わった確認日**。
  変わらない週は動かない。「今週も確認したのに日付が古い」は正常
- `meta.aircraftAsOf` … 機材・運航会社も含めて便データが最後に変わった日
- `meta.season` … `asOf` から IATA シーズンで計算（3月最終日曜から10月最終日曜の前日までが夏、
  1〜3月の冬は前年扱いで「2026冬」）

**便データに変化がない週はコミットしない**（確認日だけのコミットを積まないため）。
確認自体が動いたかは Actions の実行履歴の Summary で見る。

## 機材と運航会社の決め方

機材の優先順: ①空席データの実機材（`src:"jal"`）②FlightAware の `<meta name="aircrafttype">`（`src:"fa"`）
③前回値 ④同じ路線の多数派（`src:"majority"`）。
FlightAware は1回あたり150便まで。未解決の便を先に、残りは週番号から決めた順番で回すので、
全便はおよそ5週で一巡する。**「いつ確認したか」は持たせない**（毎週の差分になるため）。
`since` はその機材になった日。

運航会社の優先順: ①前回値（夏ダイヤの951便で初期化）②便名の接頭辞（NU=JTA、RAC=RAC）
③同じ路線で機材も同じ便 ④便番号の百の位の多数派。FlightAware の meta からは運航会社は取らない。

## 路線が時刻表から消えたとき

前回まであって今回の時刻表に無い路線は、破線（`planned:true`、「掲載なし」）で残し、
400日で消す。記憶や手入力で路線を足さないこと。

## 安全弁（コミットせず失敗で終わる）

便数が前回比 ±30% 超／空港数が15%超の減少／羽田発が100便未満／便0件／
取得できた空港ページが80未満／駅探に繋がらない。失敗すると GitHub から失敗通知メールが届く。
ダイヤ改正で本当に±30%を超えたときは `MAX_FLIGHT_CHANGE` を一時的に広げて手動実行する。

ページ構成の変更で壊れたら `parse_page()` を直す。検証は「空席データの便（JAL公式）と
便名・路線・時刻が全一致するか」が確実（初回 231/231 一致）。

## 注意

- GitHub は、リポジトリの活動が60日間ない public リポジトリの schedule を自動で止める。
  止まっていたら Actions タブから再度有効にする
- 新しい機材コードが出たら、`FA_AC` / `SEATS_AC` と `index.html` の `AC`・`ACSHORT` に足す
  （足すまでは機材名がコードのまま表示される）
- 空港は `index.html` の `AP` にあるものだけ。増えたら `NAME_TO_IATA` と `AP` に足す。
  足すまでは除外して Summary に警告が出る
