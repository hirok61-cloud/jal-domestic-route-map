2ブックマークに登録する

下のボタンを、ブラウザのブックマークバーにドラッグ＆ドロップして登録します。

✈ JAL空席を更新
ブックマークバーが出ていないときは ⌘⇧B（Windowsは Ctrl+Shift+B）で表示できます。
ドラッグしづらいときは、「コピー」して手作りのブックマークのURL欄に貼り付けてもOKです。

スマホにはブックマークバーがないので、ブックマークを1つ作って、そのURLを差し替えます。

  1. 下の「ブックマークレットをコピー」を押す
  2. Safariの共有ボタン（四角に↑のアイコン）→「ブックマークを追加」→ 保存
    （このページをそのままブックマークして構いません）
  3. ブックマーク一覧（本のアイコン）→「編集」→ いま追加したブックマークをタップ
  4. 名前を JAL空席を更新 に、URL欄を全部消して長押し→ペースト→「完了」

使うとき: JALの空席照会の画面で、ブックマーク一覧（本のアイコン）を開いて 「JAL空席を更新」をタップします。アドレスバーに直接貼り付けても動きません。

Chromeはブックマークを名前で呼び出します。短い名前を付けるのがコツです。

  1. 下の「ブックマークレットをコピー」を押す
  2. Chromeの ⋮ → ☆ でこのページをブックマークする
  3. ⋮ →「ブックマーク」→ いま追加したものを長押し →「編集」
  4. 名前を jalseat に、URL欄を全部消してペースト→ 保存

使うとき: JALの空席照会の画面でアドレスバーに jalseat と入力し、 出てきたブックマークの候補をタップします。 （javascript: をアドレスバーに直接貼り付けても、Chromeが消してしまい動きません）

3使うとき

  1. JAL公式サイトで国内線をふつうに1回検索して、予約（空席照会）の画面まで進む
    路線・日付は何でもかまいません。JALのセッションを作るためだけに使います。
  2. ブックマークバーの 「✈ JAL空席を更新」 をクリック
  3. 画面の右下に進捗が出ます。90秒ほどで終わり、そのままサイトに反映されます
JALのサーバーには70回リクエストを送るので、1.2秒ずつ間隔をあけています。 続けて何度も実行しないでください。

スマホの注意: 収集中はその画面を開いたままにしてください。 ほかのアプリに切り替えたり画面が消えたりすると、ブラウザが処理を止めてしまい 途中で失敗します（自動で画面スリープを抑えますが、手動ロックには勝てません）。

うまくいかないとき

「この画面では実行できません」と出た → JALの予約（空席照会）画面ではないところで押しています。手順3の1からやり直してください。
「送信に失敗しました」と出た → 合言葉が違うか、保存先が落ちています。このとき availability.json が自動でダウンロードされるので、リポジトリの data/ に置いて push すれば反映できます。
ボタンを押しても何も出ない → 合言葉を入れ直して、ブックマークを登録し直してください。
