空席データの更新のやり方

← 空席状況にもどる

更新のしかたは2つあります

  1. サイトの更新ボタンを押す（ふだんはこちら）
    PCのChromeに拡張を入れておく方法。スマホから押しても、そのPCが代わりに取りに行きます。
  2. スマホのブックマークレットを使う（PCが寝ているとき）
    スマホだけで完結する方法。設定が要るのは最初の1回だけです。

どちらで取っても、保存されるデータは同じです。

なぜ手で実行するのか

JALの空席は人が開いたブラウザの中からしか取得できません。サーバーからの取得はJAL側のBot対策で 弾かれ、空席の問い合わせ先もJALの予約画面からしか呼べないためです。そこで、取得はブラウザで行い、 結果だけをこのサイトに保存する形にしています。

取得するのは羽田発着35路線（往復70区間）の空席と、空席がある便の座席表です。 運賃の残席と座席表は別々に管理されていて、運賃が「空席あり」でも座席表は満席ということが 普通に起きるので、両方を見ています。

1日分で8〜10分かかります。 空席の問い合わせ70回に加えて、座席表を1便ずつ約345回見るためです。 JALのサーバーへは1.2秒ずつ間隔をあけて送っています。続けて何度も実行しないでください。 通信量も1日分で約35MBあるので、スマホではWi-Fiをおすすめします。

方法1：サイトの更新ボタン

空席状況ページのボタンを押すだけです。JALのページを開く必要はありません。 スマホから押したときも、拡張を入れたPCが代わりに取りに行きます。

ボタンは3つあります

  • 「今日分を更新」／「明日分を更新」（赤）
    搭乗日タブで選んでいる日の空席を取り直します。ボタンに対象の日が出るので、押す前に確認できます。
  • 「制度枠を記録」（紺）
    JALオンライン（法人・制度利用）で予約できる便を記録します。約3分。 先にPCのChromeでJALオンラインにログインし、企業（ＬＴ００）を選んだタブを開いたままにしておいてください（検索は不要です）。
  • 「詳細レポート」（紺）
    これまでに記録した制度枠をすべて読み込んで、傾向をまとめて表示します。

ボタンの下の細い帯に、空席・制度枠それぞれ最後に取れた時刻が出ます。 失敗していれば理由つきで赤く出るので、ちゃんと取れているかはここを見れば分かります。

拡張の入れ方（最初の1回だけ・PC）

  1. このリポジトリの extension/ フォルダをPCに用意する
    （git clone 済みなら、そのフォルダでかまいません）
  2. Chromeで chrome://extensions を開き、右上の「デベロッパーモード」をONにする
  3. 「パッケージ化されていない拡張機能を読み込む」を押して extension/ フォルダを選ぶ
  4. 拡張のアイコンを押して、合言葉（下の手順1と同じもの）を貼り付ける
PCが寝ていると通りません。 スマホから押した更新は、拡張を入れたPCのChromeが動いているときだけ通ります。 始まらないときは「3分待っても拡張が実行しませんでした」と出るので、そのときは方法2を使ってください （前の収集がまだ終わっていないときにも、同じ表示が出ます）。
収集の中身を直したときは、chrome://extensions で拡張を再読み込みしてください。 読み込み直すまで古いままのコードが動きます。

方法2：スマホのブックマークレット

PCが寝ていてもスマホだけで完結する方法です。下の手順1〜2で登録し、手順3で使います。 PCでは不要です（拡張が入っていれば、同じことをボタン1つでやってくれます）。

1合言葉を入れる（最初の1回だけ）

保存するときに使う合言葉です。この端末のブラウザにだけ保存され、どこにも送信しません。

未入力です。

2ブックマークに登録する

スマホにはブックマークバーがないので、ブックマークを1つ作って、そのURLを差し替えます。

  1. 下の「ブックマークレットをコピー」を押す
  2. Safariの共有ボタン（四角に↑のアイコン）→「ブックマークを追加」→ 保存
    （このページをそのままブックマークしてかまいません）
  3. ブックマーク一覧（本のアイコン）→「編集」→ いま追加したブックマークをタップ
  4. 名前を JAL空席を更新 に変え、URL欄を全部消して、長押し→ペースト→「完了」

呼び出し方: JALの画面を開いた状態で、ブックマーク一覧（本のアイコン）から 「JAL空席を更新」をタップします。アドレスバーに直接貼り付けても動きません。

Chromeはブックマークを名前で呼び出します。短い名前を付けるのがコツです。

  1. 下の「ブックマークレットをコピー」を押す
  2. Chromeの ⋮ → ☆ でこのページをブックマークする
  3. ⋮ →「ブックマーク」→ いま追加したものを長押し →「編集」
  4. 名前を jalseat に変え、URL欄を全部消してペースト→ 保存

呼び出し方: JALの画面を開いた状態でアドレスバーに jalseat と入力し、 出てきたブックマークの候補をタップします。 ブックマーク一覧から開くと、JALのページではなく新しいタブで動いてしまい失敗します。 （javascript: をアドレスバーに直接貼り付けても、Chromeが消してしまい動きません）

3使うとき

  1. JAL公式サイトを開く
    検索は不要です。開くだけでかまいません。
  2. ブックマークバーの 「JAL空席を更新」 をクリック
  3. 30秒ほど待つと空席照会の画面に切り替わるので、そこでもう一度同じブックマークを呼び出す
    JALの空席は、この画面の上からしか取得できない決まりになっています。
  4. 右下に「今日 / 明日 / 両日 / 制度枠（今日）」が出るので、更新したいものをタップする
  5. そのまま進捗が出ます。1日分で8〜10分、終わるとサイトに反映されます
収集中は、その画面を開いたままにしてください。 ほかのアプリに切り替えたり画面が消えたりすると、ブラウザが処理を止めてしまい途中で失敗します （自動で画面スリープを抑えますが、手動ロックには勝てません）。
「制度枠（今日）」はJALオンライン（法人・制度利用）専用です。 JALオンラインにログインし、企業（ＬＴ００）を選んだ状態で押してください（検索は不要）。約3分で終わります。 ふだんの空席を更新したいときは、今日・明日・両日のどれかを選んでください。

うまくいかないとき

「この画面では実行できません」
JALの予約（空席照会）の画面ではないところで押しています。上の「使うとき」の1からやり直してください。

「ログイン情報が見つかりません」
画面を開いた直後か、しばらく放置してJAL側のセッションが切れています。国内線を1回検索して、便が並んだ画面で押し直してください （制度枠のときは、JALオンラインを開き直してください。無操作だと約1時間で切れます）。

「収集スクリプトを読み込めませんでした」
配信元3か所すべてに届いていません。枠にどこで何が起きたかが並ぶので、通信できる状態か確かめて、もう一度押してください。

途中で止まった
空席の一覧は問い合わせが終わった時点でいったん保存しているので、座席表の途中で止まっても一覧は最新になっています。 もう一度実行すれば、座席表から取り直します。

呼び出しても何も出ない
合言葉を入れ直して、ブックマークを登録し直してください。Androidは、ブックマーク一覧からではなく アドレスバーに名前を入れて候補をタップしているか確かめてください。

取得はできたのに、保存だけ失敗するとき

端末に入れているセキュリティ対策アプリや広告ブロック系のアプリが、「サイトの外へ送る通信」を 止めてしまうことがあります。サイトの不具合ではありません。

そのため保存は、うまくいくまで送り方を自動で切り替えて何通りか試します。 普段のやり方が止められていても、多くの場合は何もしなくても最終的に保存できます。 いくつか試すぶん、成功／失敗が分かるまで数十秒かかることがあります（待っていて大丈夫です）。

それでもだめだったとき: その回の結果（availability-日付.json）が自動でダウンロードされます。 消さずに残して、PC側の担当に渡してください。手元でその日ぶんだけ反映できます。 あわせて、失敗表示の「内容をコピー」を押して、その文面も送ってください。原因の切り分けに使えます。
