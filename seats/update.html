空席データの更新のやり方

← 空席状況にもどる

どういう仕組みか

JALの空席は人が開いたブラウザの中からしか取得できません。 サーバーからの取得はJAL側のBot対策で弾かれ、空席APIもJALの予約サイトの画面からしか呼べないためです。 そこで、収集はブラウザで行い、結果だけをサイトに保存する形にしています。

取得するのは羽田発着35路線（往復70区間）の空席と、 空席がある便の座席表です。運賃の在庫と座席表は別管理で、 運賃が「空席あり」でも座席表は埋まっていることがあるため、両方を見ています。

1日分あたり8〜10分かかります。 空席照会70回に加えて、座席表を1便ずつ約345回見るためです。 そのため時間がかかるので、更新は「今日分」「明日分」を選んで実行します。

方法1：サイトのボタン（PCに拡張を入れておく）

Chrome拡張をPCに入れておくと、空席状況ページの更新ボタンを押すだけで済みます。 JALのページを開く必要はありません。スマホから押したときも、このPCが代わりに取りに行きます。

  1. リポジトリの extension/ フォルダをローカルに用意する
    （git clone 済みならそのフォルダでOK）
  2. Chromeで chrome://extensions を開き、右上の「デベロッパーモード」をON
  3. 「パッケージ化されていない拡張機能を読み込む」→ extension/ フォルダを選ぶ
  4. 拡張のアイコンを押して、合言葉（下と同じもの）を貼り付ける

使うときは、空席状況ページで搭乗日タブ（今日／明日）を選んでから 更新ボタンを押します。ボタンには 「今日分を更新」「明日分を更新」 と対象が出るので、 押す前に確認できます。選んだ日だけを取り直すので8〜10分で終わります。

PCが起きている必要があります。 スマホから押した更新は、このPCのChromeが動いているときだけ通ります。 スリープ中は3分で「Macが起動していなかったため実行されませんでした」になるので、 そのときは下のブックマークレットを使ってください。

方法2：スマホのブックマークレット（PCが寝ているとき）

スマホだけで完結する方法です。実行すると最初に 「今日 / 明日 / 両日」を聞かれるので、必要な日を選びます。以下の1〜3で設定します。

パソコンでは不要です（拡張が入っていれば、同じことをボタン1つでやってくれます）。

1合言葉を入れる（最初の1回だけ）

書き込み用の合言葉です。この端末のブラウザにだけ保存され、どこにも送信しません。

未入力です。

2ブックマークに登録する

スマホにはブックマークバーがないので、ブックマークを1つ作って、そのURLを差し替えます。

  1. 下の「ブックマークレットをコピー」を押す
  2. Safariの共有ボタン（四角に↑のアイコン）→「ブックマークを追加」→ 保存
    （このページをそのままブックマークして構いません）
  3. ブックマーク一覧（本のアイコン）→「編集」→ いま追加したブックマークをタップ
  4. 名前を JAL空席を更新 に、URL欄を全部消して長押し→ペースト→「完了」

使うとき: JALの空席照会の画面で、ブックマーク一覧（本のアイコン）を開いて 「JAL空席を更新」をタップします。アドレスバーに直接貼り付けても動きません。
動かないときは: 下の「動作テストをコピー」で別のブックマーク（JALテスト）を作り、 同じ手順で呼び出してください。白い枠に booking.jal.co.jp と出れば正常です。

Chromeはブックマークを名前で呼び出します。短い名前を付けるのがコツです。

  1. 下の「ブックマークレットをコピー」を押す
  2. Chromeの ⋮ → ☆ でこのページをブックマークする
  3. ⋮ →「ブックマーク」→ いま追加したものを長押し →「編集」
  4. 名前を jalseat に、URL欄を全部消してペースト→ 保存

使うとき: JALの空席照会の画面でアドレスバーに jalseat と入力し、 出てきたブックマークの候補をタップします。 ブックマーク一覧から開くと、JALのページではなく新しいタブで動いてしまい失敗します。 （javascript: をアドレスバーに直接貼り付けても、Chromeが消してしまい動きません）
動かないときは、まずこれで切り分けてください。 下の「動作テストをコピー」でもう1つ別のブックマーク（名前は jaltest）を作り、 JALの画面で同じように呼び出します。
  • 白い枠が出て booking.jal.co.jp と表示 → 正常。本番も動きます
  • 白い枠は出るが別のホスト名 → 呼び出し方が違います（アドレスバー経由にしてください）
  • 何も出ない → お使いのChromeがブックマークレットを実行できません

3使うとき

  1. JAL公式サイトを開く
    検索は不要です。開くだけでかまいません。
  2. ブックマークバーの 「✈ JAL空席を更新」 をクリック
  3. 30秒ほど待つと空席照会の画面に切り替わるので、そこでもう一度同じブックマークを押す
    JALの空席は、この画面の上からしか取得できない決まりになっています。
  4. 「今日 / 明日 / 両日」を聞かれるので、更新したい日をタップする
  5. 画面の右下に進捗が出ます。1日分で8〜10分かかり、終わるとそのままサイトに反映されます
JALのサーバーには1日分あたり約415回リクエストを送るので、1.2秒ずつ間隔をあけています。 続けて何度も実行しないでください。 通信量も1日分で約35MBあるので、スマホではWi-Fiをおすすめします。

スマホの注意: 収集中はその画面を開いたままにしてください。 ほかのアプリに切り替えたり画面が消えたりすると、ブラウザが処理を止めてしまい 途中で失敗します（自動で画面スリープを抑えますが、手動ロックには勝てません）。

うまくいかないとき

「この画面では実行できません」と出た → JALの予約（空席照会）画面ではないところで押しています。手順3の1からやり直してください。
「送信に失敗しました」と出た → 合言葉が違うか、保存先が落ちています。このとき availability.json が自動でダウンロードされるので、リポジトリの data/ に置いて push すれば反映できます。
途中で止まった → 空席照会が終わった時点でいったん保存しているので、座席表の途中で止まっても空席の一覧は最新になっています。もう一度実行すれば座席表から取り直します。
ボタンを押しても何も出ない → 合言葉を入れ直して、ブックマークを登録し直してください。
